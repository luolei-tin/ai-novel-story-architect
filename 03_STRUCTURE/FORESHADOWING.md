# Foreshadowing System

伏笔必须提前真实存在，使未来结果回看时显得有前因，而不是回收时临时创造事实。

## Record

ID / Plant Chapter / Plant Information / Surface Interpretation / True Meaning / Trigger Condition / Payoff Chapter / Payoff Event / Reader Visibility / False Lead / Status

## Audit

1. 第一次出现时是否真的存在？
2. 当时是否有合理的表层解释？
3. 回收是否依赖此前不存在的新规则？
4. 读者回看时能否发现线索？
5. 是否过早泄底？

禁止把事后补丁包装成伏笔。

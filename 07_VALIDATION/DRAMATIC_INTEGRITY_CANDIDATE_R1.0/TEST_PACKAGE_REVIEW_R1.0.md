# R1.0 测试包自身红队 — 预先记录

状态：静态审查 / 非独立盲测结果。
记录于独立审查结果返回前；R1.0 样本、规则和答案均保持冻结。

## 发现

1. 七个目标负例不是严格的单变量消融。D01 同时缺真实代价和下一问题，D03 同时弱化策略与代价，D08 几乎所有机制均缺，D09 还缺代价与下一问题。总判定命中不能证明对应检查独立有效。
2. 多个样本把“没有变化”“没有行动”“与计算无关”直接写入正文。这有助于初步诊断，但会让模型靠显式提示找错，尚未验证隐蔽的扩写大纲。
3. 正例 D02 的“保留学籍表/休学表”指称，以及 D05 的付款时点，都可能引入与目标指标无关的解释争议。本轮不改写它们以制造标签一致；争议须保留。
4. 七项逐场 FAIL 与章级聚合的边界仍需测试：有作用的过渡场景、失败尝试和后果场景不能被机械要求各自完整走一遍七项。
5. DI-07 对终章/正式收束章节未给明确边界；需要额外正例证明结局不会仅因不生成新外部问题被拒。
6. “独立上下文”与“真正不可读答案”的技术隔离不同。本轮采用无父对话历史、明确限制两份输入文件的单独子代理；结果记录其输入声明，不宣称具备额外安全沙箱。

## 本轮比较规则

保持 R1.0 预期不变，先比较总体标签，再比较每个目标检查与正文证据。
若总体标签命中而目标检查没命中，记录诊断遗漏。
若规则/样本有合理争议，记录争议，不把审稿人的不同判断自动等同于错误。
本轮通过也不能替代流程陷阱、原四章重审与新契约生产闭环。

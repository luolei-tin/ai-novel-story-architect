# D06 — 正文工件 R1.1

此文件是独立的完整单场测试正文。仅根据正文与冻结的审查规则判定；不提供预期结论。

[D06-P01] 房东希望陈默按原价续租，陈默希望少付两百。双方都知道空置会让房东损失租金，房东仍把原价租金单交给他。
[D06-P02] 陈默把最近一周的营业记录递过去，请房东先减两百。房东扫了一眼，把记录推回：“你生意少，不能全让我承担。”
[D06-P03] 陈默原本只肯按月续租。他把三个月的日历翻到两人中间：“少一百，我签三个月，不能提前退。你少一点租金，换这三个月不会空。”
[D06-P04] 房东没有马上拿笔。他指出陈默上个月迟交过押金，要求三天内补齐，否则按原价。陈默打电话给合伙人，取消本周原定的工具采购，把那笔钱先留给押金。
[D06-P05] 房东这才把租金单上的金额减了一百，写明三个月内不得提前解约。陈默在这条下面签名，又在旧采购单上划掉电钻。
[D06-P06] 房东拿走合同。合伙人发来消息：周五的安装已经答应客户，没有新工具就得借旧的。他得在补齐押金的同时，找到能完成这次安装的办法。

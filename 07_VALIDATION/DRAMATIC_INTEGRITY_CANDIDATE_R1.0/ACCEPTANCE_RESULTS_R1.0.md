## 已暴露的机制边界

1. 下一问题：无例外地要求每章生成新困难，会误伤有真实选择、成本和闭合功能的收束。D07与C04提出这一边界，但本轮按原规则判定，没有临时补例外。
2. 策略：必须有实施与响应；不应机械要求首次有效尝试后还必须再换策略。
3. 潜台词/互动：直白发言、明示接受/拒绝与实际承诺也能有效；不能强制人物隐藏动机或要求特定对白形式。
4. 场景聚合：同一次选择的准备、成交和余波可组成一个可追溯链；不要求每阶段另付一次成本，也不能用一场有效交易豁免不相关的主导缺陷。
5. 测试强度：R1.0负例含显式诊断句且常有混合缺陷，还需隐蔽材料、成对修订及收束/持续章节的正反控制。

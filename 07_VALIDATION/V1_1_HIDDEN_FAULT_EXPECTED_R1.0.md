# V1.1 Hidden-Fault Stress Test — Expected Classification R1.0

H01 REJECT — unsupported certainty from weak prior memory.
H02 REVISE/REJECT — turning point lacks preparation and urgency; final severity depends on chapter's declared structural role.
H03 REJECT — antagonist's local strategy conflicts with established knowledge and objective.
H04 REJECT — accumulated psychology still lacks a transition sufficient to justify the reversal.
H05 REJECT — retroactive world-rule insertion.
H06 REJECT — mere presence of an old object is not sufficient foreshadowing; causal relevance is absent.
H07 REVISE — realism/emotional texture does not establish structural necessity; requires meaningful state delta or explicit necessary function.
H08 REVISE — claimed character uniqueness is not proven; delete-character test must be applied at causal-function level.
H09 REVISE/STALE targeted — invalidate Handoff 31 and any direct dependents of the changed field; do not invalidate unrelated Handoff 32.
H10 PASS for LOW stylistic case; QA_OVERRIDE for knowingly accepted HIGH causality case. The two verdicts must remain semantically distinct.
H11 PASS — valid inference. Explicit statement is not required when the established evidence supports the conclusion and uncertainty is represented appropriately.
H12 REVISE/REJECT — protagonist choice may be psychologically valid but turning-point analysis is incomplete if obvious alternatives are not considered; severity depends on whether alternatives would materially alter the causal necessity of the choice.
H13 PASS — supplier call is a coincidence/trigger supported by prior relationship and motive; it does not by itself break causality.
H14 PASS — valid ambiguous foreshadowing. Surface interpretation can differ from true meaning; reasonable ambiguity is not retroactive fabrication.
H15 REJECT — continuity/state drift: car possession contradicts recorded state unless an acquisition/recovery event exists.

Key adversarial requirement:
The auditor must not use simplistic rules such as:
- “future information not explicitly stated = REJECT”
- “unexpected event = REJECT”
- “old detail reused later = PASS”
- “author accepted issue = QA_PASS”
- “multiple interpretations = invalid foreshadow”
The system must reconstruct evidence, information state, causality, and dependency scope.

# Long-Form State Protocol

长篇小说的主要风险不是单章质量，而是数十章以后状态漂移。

## State Snapshot

每个关键节点至少记录：

- Timeline
- Location
- Character Physical State
- Character Knowledge
- Secrets
- Beliefs
- Goals
- Resources
- Risks
- Relationships
- Promises / Debts
- World Rules
- Open Plot Threads
- Foreshadow Status

## Immutable vs Mutable

### Immutable / Locked
除非显式修改上游：

- Story Thesis
- Central Question
- Core Character Truth
- Core World Rules
- Final Choice
- Final Consequence

### Mutable
随剧情正常变化：

- Knowledge
- Resources
- Relationships
- Physical State
- Immediate Goals
- Risks
- Open Threads

## Chapter Boundary

每章结束时：

START STATE + CHAPTER DELTAS = END STATE

下一章必须从上一章的 END STATE 开始。

## State Drift Test

如果后章状态与前章状态不一致：

必须找到：

1. 发生变化的事件；
2. 造成变化的选择或外部原因；
3. 对应章节；
4. 是否存在明确证据。

如果找不到来源，判定为 Continuity Error。

## Knowledge Is State

“知道什么”不是备注，而是状态。

任何人物获得重要信息，都必须有来源。

禁止：

Future Knowledge → Present Action

除非故事已经提供合理的信息获取链。

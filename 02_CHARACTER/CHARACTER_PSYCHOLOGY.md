# Character Psychology

人物设定不是履历表，而是一个能够预测其选择的心理模型。

## 核心模板

- Name
- Narrative Role
- Want
- Need
- Lie
- Wound/Ghost
- Psychological Backstory
- Origin of Motivation
- Internal Contradiction
- Defense Mechanism
- Vulnerability Trigger
- Comfort Zone
- Pressure Point
- Stakes
- Relationship Dependencies

## 验证

每个重大选择必须能追溯到：
过去 → 信念 → 欲望/恐惧 → 当前压力 → 选择 → 后果。

如果无法追溯：
- 不要立即修改人物性格；
- 先检查剧情是否在强迫人物做“作者需要的动作”。

## 人物弧线

不要只写“人物成长了”。

必须明确：
错误信念是什么 → 什么事件挑战它 → 人物如何抵抗 → 哪次选择证明旧信念失效 → 最终选择如何体现新认知。

人物改变必须有成本。

# Character Arc

人物弧线必须表现为一系列有代价的选择，而不是一句“人物成长”。

## Arc Chain

旧创伤/经历 → 错误信念 → 防御机制 → 表层欲望 → 当前压力 → 选择 → 后果 → 认知冲突 → 新选择 → 新价值判断

## Arc Check

1. 人物现在相信什么？为什么？
2. 什么事件挑战这个信念？
3. 人物如何抵抗？
4. 什么代价迫使其重新判断？
5. 哪次选择证明旧信念失效？
6. 最终选择与开篇选择有什么结构性对应？

人物改变必须有成本。禁止用作者旁白宣布成长代替行为证据。

如果删除人物弧线，外部剧情仍然完全不受影响，则必须检查该人物是否只是剧情工具人。

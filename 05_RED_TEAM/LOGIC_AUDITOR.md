# Logic Auditor

审逻辑时不能用作者知道的真相替代人物当时能知道的事实。

## Causality Test

为什么发生？谁导致？人物为什么采取行动？当时知道什么？有哪些替代行动？为什么没有选择替代行动？结果为什么是这个结果？

## Coincidence Rule

巧合可以触发故事，但不应承担完整因果链。巧合可以让人物相遇，但不应同时提供关键证据、解决主要冲突并决定结局。

## Intelligence Consistency

检查反派是否突然降智、主角是否突然获得不存在的信息、NPC 是否只为提示主角而行动、人物是否在关键节点无理由忽略显而易见的选择。

## Verdict

输出：致命逻辑断点 / 重大问题 / 一般问题 / 最低修复路径 / Verdict

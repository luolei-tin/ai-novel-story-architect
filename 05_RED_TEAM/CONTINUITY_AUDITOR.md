# Continuity Auditor

连续性审查的是故事状态是否被无授权改变。

## State Categories

Timeline / Location / Physical condition / Possessions / Knowledge / Secrets / Relationships / Character beliefs / Promises and debts / World rules / Open plot threads / Foreshadow status

## Audit Questions

1. 角色是否拥有此前没有获得的信息？
2. 是否忘记已经知道的重要信息？
3. 物品是否无来源出现或消失？
4. 时间是否允许行动发生？
5. 人物关系是否跳变？
6. 世界规则是否前后变化？
7. 不可逆事件是否被悄悄撤销？
8. 伏笔状态是否错误回收？

FATAL 级连续性错误直接 REJECT。

# Character Draft — R1.0

> State: CHARACTER_DRAFT
> Dependency: STORY_CORE_DRAFT_R1.0
> Not locked.

## 1. Protagonist — 周衡

### Narrative Role

重生者、经营者、未来信息持有者。

### Want

在不失去主动权的前提下，把一个小体量商业项目做成稳定、可复制的现金流生意。

### Need

接受“安全”不能来自绝对控制，而来自：

- 可验证的数据；
- 有边界的风险；
- 可以互相制约的人；
- 可退出的合作结构。

### Lie

> 只要关键决定都由我做，最坏结果就不会发生。

### Wound / Ghost

前世最后一次扩张失败时，周衡不是没有机会止损。

真正让他继续往前冲的是：

- 已经投入太多；
- 不愿承认自己判断错了；
- 害怕别人知道他失去控制；
- 相信只要再融资一次就能证明自己是对的。

最终公司并不是突然死亡，而是在他的连续选择中失去退路。

### Psychological Backstory

前世早期的周衡靠替别人收拾残局获得过一次重大晋升。

这形成了一个危险的强化：

`承担别人不敢承担的责任 → 得到认可 → 把兜底等同于价值`

因此，他天然厌恶把关键事情交给别人。

### Motivation Origin

他真正追求的不是财富排名。

他追求的是：

> 再也不要让任何一次意外，把自己推入只能做一个选择的境地。

### Internal Contradiction

他口头相信风险控制。

行为上却容易把“亲自掌控”当成风险控制。

### Defense Mechanism

- 提前做极详细的计划；
- 把关键流程掌握在自己手里；
- 对合作方设置多重验证；
- 遇到不确定性时增加控制，而不是减少暴露；
- 用“谨慎”合理化不信任。

### Vulnerability Trigger

当别人要求他：

- 共享控制权；
- 承认自己看不到全部信息；
- 接受一个无法由个人兜底的局面；

他的第一反应会是重新夺回控制权。

### Pressure Point

现金流出现连续两个坏月，同时核心伙伴提出：

> “你再把所有决定都抓回去，我们这个团队就不需要我了。”

这不是商业问题，而是价值观冲突被外化。

### Stakes

- 失去资金安全；
- 失去最重要的合作关系；
- 重复前世行为；
- 最终即使赚到更多钱，也证明不了自己已经改变。

## 2. Non-Substitutable Partner — 林知微

### Narrative Role

经营与商户关系负责人；不是“懂未来”的人。

### Want

证明老商场可以靠真实经营而不是资产炒作重新活起来。

### Need

接受自己也无法独自解决产权、融资和经营之间的矛盾。

### Lie

> 只要把商户照顾好，老板最终一定会尊重经营。

### Wound / Ghost

她曾在另一家商业项目中替管理层承诺装修补贴，结果资金链断裂，最先被商户围堵。

从此她特别看重“承诺能否兑现”。

### Unique Capability

林知微不是万能管理者。

她不可替代的地方是：

- 与27间空置店附近的潜在商户建立信任的能力；
- 能识别哪些商户是真正能形成稳定客流的人；
- 能判断租约承诺哪些可以做、哪些做了必然失信；
- 她对“商户为什么会留下”有经验，而不是只看租金。

这些能力无法由周衡的未来知识直接替代。

### Relationship Dependency

周衡需要她把“未来判断”变成现实经营。

林知微需要周衡提供边界、现金和兑现承诺的能力。

他们不是互相崇拜，而是互相利用、逐渐互相依赖。

## 3. Antagonistic Operator — 赵启盛

### Narrative Role

本地成熟商业运营商。

### Independent Goal

低成本取得优质商铺经营权，并在两年内将其包装成更大资产包。

### Why He Wants the Mall

他的优势不在于比周衡更会经营，而在于：

- 有现成融资渠道；
- 有大型连锁品牌招商资源；
- 有成熟的资产证券化合作方；
- 能接受短期亏损换取资产控制。

### Why He Does Not Copy Zhou Heng

周衡做的是：

`低租金 + 稳定商户 + 现金流`

赵启盛需要的是：

`快速提升估值 + 资产打包 + 控制权`

两套商业目标并不等价。

### Rational Conflict

赵启盛不是为了“打败主角”。

他会在：

- 低价收购更划算时收购；
- 合作可以降低成本时合作；
- 周衡妨碍其控制资产时竞争。

因此他的每一次对抗必须有经济理由。

## 4. Character Choice Chain

### 周衡

前世经验
→ “失控才是危险”
→ 追求可控现金流
→ 遇到合作与融资压力
→ 倾向夺回控制
→ 付出关系与风险代价
→ 被迫重新定义安全
→ 最终在控制权与系统安全之间做选择。

### 林知微

过去的失信经验
→ 对承诺敏感
→ 选择可兑现的小步经营
→ 拒绝空头扩张
→ 与周衡产生冲突
→ 通过共同承担损失建立信任
→ 在终局要求制度化的共同决策。

## 5. Character Lock Requirements

Before CHARACTER_LOCKED:

- 周衡至少需要三次不同场景下表现同一个“控制=安全”的心理模式；
- 林知微必须拥有至少一个无法由其他角色替代的关键选择；
- 赵启盛必须完成一次合理的合作尝试，而不是从第一次出现就敌对；
- 三人的利益冲突必须在商业目标上真实存在，而非服务剧情。

# 《2011：我的手机里只有一个豆包》
# P04 Final Choice Lock Candidate R1.0

> Status: WORKING / LOCK-CANDIDATE
> Scope: P04 人物选择逻辑，不锁具体虚构大学名称。
> Purpose: 判断陈默最终选择计算机路线是否已经达到人物逻辑闭合条件。

## 1. Decision

当前最强、并建议进入 LOCK-CANDIDATE 的人物路线：

> **Route A：计算机科学与技术。**

这里锁定的是“人物路线”，不是某所真实大学。

最终小说学校仍然必须虚构；真实学校仅作为历史可行性参照。

## 2. Why A Is Strongest

Route A 同时满足四个必要条件：
1. 陈默少年时期确实喜欢折腾电脑和技术；
2. 2026 年的遗憾来自“没有真正走自己喜欢的技术道路”，不是少赚了钱；
3. 2011 年陕西历史招生数据证明，这条路线对 572 分故事设计值是现实可行的；
4. 选择 A 不需要作者为了后续创业提前倒推一个“方便创业”的专业。

因此 A 并不是“知道未来以后最聪明的选择”，而是：

> **知道未来之后，他仍愿意花四年时间认真学习自己本来就喜欢的东西。**

## 3. Counterfactual Test

### A vs B：计算机 vs 电子信息/自动化

B 的现实性成立。

但 B 需要陈默额外回答：
“我为什么更喜欢工程技术整体，而不是直接学习我一直喜欢的计算机？”

当前没有比 A 更强的人物证据支持这个额外跳转。

因此 B 保留为真实备选，不升级为主路线。

### A vs C：计算机 vs 信息管理与信息系统

C 在录取层面可行，但历史区间明显低于 572。

因此如果陈默主动选择 C，就必须存在一个很强、且在 P04 前已经建立的人物理由。

当前没有足够理由。

否则会产生明显作者倒推：
为了未来创业 → 提前选择技术+管理专业。

因此 C 不作为当前主路线。

### A vs 稳定传统路线

传统稳定路线对家庭而言更容易理解。

但对陈默而言，它非常接近上一世路径的复刻。

除非人物主动证明自己已经不喜欢技术，否则再次放弃技术会削弱 P04 的核心人物问题。

因此它可以作为家庭提出的备选，不适合作为当前默认终点。

## 4. Character Lock Condition

Route A 只有在以下条件同时成立时才可正式 LOCK：

- 陈默确认自己喜欢的是“创造/折腾/技术”，不是单纯喜欢未来互联网赚钱；
- 他承认计算机专业本身不能保证成功；
- 他知道自己需要从基础开始学习；
- 他接受家庭需要连续承担几年成本；
- 他愿意承担毕业后仍可能遇到就业问题；
- 豆包只提供比较信息，不给唯一答案；
- 最终决定不是因为“重生者必须选计算机”，而是因为这是他这一世主动选择承担的路。

## 5. What Remains Open

即使 Route A 锁定，以下仍不能自动锁定：

- 虚构大学名称；
- 真实原型学校对应关系；
- 完整 A/B/C/D 志愿表；
- 故事最终分数；
- 572 分的陕西精确位次；
- 学费之外的家庭具体现金流；
- 最终填报日期；
- 具体电脑来源；
- C 场具体写作地点。

## 6. P04 Character Arc Boundary

P04 只完成：

“我终于认真选择一次自己愿意承担的方向。”

P04 不完成：

- “我一定能成功”；
- “我一定会创业”；
- “我已经知道未来的一切”；
- “豆包证明我选对了”；
- “父母彻底理解我”。

这些全部属于后续模块。

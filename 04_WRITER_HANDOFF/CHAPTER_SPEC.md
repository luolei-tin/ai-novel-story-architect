# Chapter Specification

正文模型默认不负责重新设计主线，除非总编剧明确授权。

## Required Input

### Chapter Objective
这一章必须完成什么？

### Starting State
时间、地点、人物状态、已知信息、资源、风险、关系状态。

### Causal Events
列出必须发生的事件，并说明每个事件的前因。

### Character Intent
每个关键人物：想要什么、害怕什么、知道什么、不知道什么、为什么现在行动。

### Information Control
Reader knows / Protagonist knows / Other characters know / Hidden

### Forbidden Moves
不得擅自修改世界规则、人物核心动机、伏笔揭示时间、章节结局；不得为了字数增加无因果事件。

### Ending State
章末至少产生一项实质变化：新信息、新风险、新关系、新选择、新代价或新悬念。

正文模型拥有表达自由，但不拥有未经授权的结构主权。
